TotemCooldown — плагин Paper для лимита тотемов.

Что делает:
- Игрок может успешно использовать один тотем бессмертия раз в 20 игровых дней.
- Пока перезарядка активна, следующий тотем не спасёт игрока от смерти.
- Таймер сохраняется в plugins/TotemCooldown/cooldowns.yml.
- Команда /totemtimer показывает оставшееся время.
- Операторы по умолчанию имеют право totemcooldown.bypass и обходят ограничение.

Время:
20 игровых дней = 480 000 серверных тиков (примерно 6 ч 40 мин, пока сервер тикает).
Отсчёт идёт по времени первого мира в списке Bukkit. Время, когда сервер выключен, не считается.

Сборка:
1. Установите JDK и Maven.
2. В терминале из папки проекта выполните: mvn package
3. Готовый JAR появится в target/totemcooldown-1.0.0.jar
4. Перенесите JAR в папку plugins сервера и перезапустите сервер.

ВАЖНО:
Версия Paper 26.3 и доступность артефакта paper-api:26.3-R0.1-SNAPSHOT зависят от того,
опубликован ли этот API в Maven-репозитории PaperMC. Если Maven сообщает, что версия не найдена,
откройте https://papermc.io/downloads/paper и используйте актуальную версию API в pom.xml.
Если ваш сервер требует другую Java-версию, поменяйте maven.compiler.release на требуемую.
